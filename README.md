ProLink is a database-driven freelancing platform developed to demonstrate practical Database Management System concepts. 
The system includes user authentication, job posting and searching, proposal submission, messaging, contracts, reviews and ratings, profiles, and transactions. 
The project also applies EER modeling, relational schema design, and normalization to ensure organized and consistent data management.


How to Run:

Install XAMPP and start Apache and MySQL.
Extract the "prolink.zip" file into the XAMPP htdocs folder.
Open phpMyAdmin by visiting "http://localhost/phpmyadmin".
Create a new database named prolink.
Import the provided "prolink.sql" file into the prolink database.
Make sure the database configuration in prolink/config/db.php uses:
Host: localhost
Username: root
Password: empty
Database: prolink
Open the project in a browser using: "http://localhost/prolink/"
